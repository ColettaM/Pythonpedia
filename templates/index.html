Pythonpédia

À propos

Pythonpédia est une encyclopédie distribuée : chaque serveur héberge une partie de la base de données et partage ses informations avec les autres serveurs du réseau. L’objectif est de construire une base de connaissances collective et ouverte sur n'importe quel type de langage de programmation.

🌐 Comment fonctionne Pythonpédia ?

Chaque ordinateur participant au projet représente un serveur du réseau Pythonpédia. Ces serveurs échangent leurs données (topics, items, URLs) grâce à une API REST commune :

  • 🔹 Chaque serveur stocke ses données dans un fichier.json ou dans une BDD.
  • 🔹 Il publie ses ressources via /ws/topics et /ws/topic/<topic>
  • 🔹 Il découvre ses pairs avec /ws/annuaire
  • 🔹 Le script sync.py permet de synchroniser automatiquement les serveurs

API publique

Pythonpédia met à disposition une API REST permettant d’accéder aux données locales (topics, items et URLs) et à la liste des serveurs connus du réseau. Pour plus de détails sur les endpoints et les exemples d’appels, consultez la documentation technique.

Comment utiliser Pythonpédia

Pour profiter pleinement du service :

  • Naviguez dans les thèmes via l’interface interactive,
  • Découvrez l’API complète dans la documentation,
  • Synchronisez vos données locales avec sync.py ou le bouton “Réplication”.
