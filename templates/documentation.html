Pythonpédia- Documentation technique

Pythonpédia est une encyclopédie collaborative et distribuée sur le langage Python. Chaque serveur héberge une partie de la base de données (topics, items et URLs) et expose une API REST publique interrogeable.

1. Structure des données

Les données sont stockées localement dans un fichier db.json :

{
  "topics": {
    "fonctions": {
      "définition": ["https://docs.python.org/..."],
      "exemple": ["https://realpython.com/..."]
    },
    "POO": {
      "tuto": ["https://realpython.com/python3-object-oriented-programming/"],
      "exemple": ["https://docs.python.org/..."]
    }
  },
  "annuaire": [
    "http://172.20.45.142:8888",
    "http://172.20.45.149:8888"
  ]
}

Chaque topic regroupe plusieurs items, et chaque item contient une ou plusieurs URLs utiles.

2. Endpoints REST publics

MéthodeURLDescriptionExemple
GET /ws/topics Renvoie la liste des topics disponibles localement. 
["types", "fonctions", "multithreading", "POO"]
GET /ws/topic/<topic> Renvoie les items et URLs d’un topic donné. 
{
  "exemple": ["https://realpython.com/..."],
  "définition": ["https://docs.python.org/..."]
}
GET /ws/annuaire Renvoie la liste des serveurs connus par le serveur local. 
[
  "http://172.20.45.142:8888",
  "http://172.20.45.149:8888"
]

3. Endpoints administratifs (protégés)

Ces routes sont réservées à l’administrateur local et nécessitent une clé API définie dans le fichier .env :

Clé par défaut : ADMIN_TOKEN=XXXX À envoyer dans le header HTTP : X-API-Key

💡 Pour des raisons de sécurité, la clé administrateur n’est pas mémorisée sur les postes : elle doit être ressaisie à chaque utilisation de l’interface.
MéthodeURLAction
POST /ws/annuaire Ajoute un nouveau serveur à l’annuaire local.
POST /admin/sync Déclenche la réplication automatique des données locales (équivaut à exécuter python3 sync.py).

4. Exemple d’utilisation

Les endpoints peuvent être testés facilement avec curl :

curl http://localhost:8888/ws/topics
curl http://localhost:8888/ws/topic/fonctions
curl http://localhost:8888/ws/annuaire

5. Réplication et découverte

Chaque serveur Pythonpédia peut s’enrichir automatiquement :

  • 🔁Réplication : fusion des topics et URLs depuis les pairs connus.
  • 🌍Découverte : ajout automatique des serveurs trouvés via /ws/annuaire.
  • 🧩Exécution locale : via le script sync.py ou la route /admin/sync.
